# 实战案例：蔚来官方号风格模仿（2026-08-13）

## 输入
用户要求："蔚来风格研究，综合小红书蔚来官方号的所有推文"

## 定位路径（输入B：博主名）
1. `search_feeds` 搜"NIO Day" → 结果中定位 @蔚来（userId=5663dbb17c5bb8369230f1b9，昵称"蔚来"，简介"共创可持续和更美好的未来"）
2. 从搜索结果笔记提取 xsecToken
3. `user_profile`（user_id 完整24位 + xsec_token + tab:note）→ 拉到全部62条笔记（113KB）

## 拉取正文
- 选7篇代表性笔记（产品发布/技术讲解/里程碑/售后荣誉/生态公益/明星合作/换电体系）
- 每篇 `get_feed_detail` 间隔≥3s
- 部分 token 失效（118字节错误）→ 重新 user_profile 刷新全部 token 后重试

## 提炼的10维指纹（摘要）
1. 人称：无主语/品牌视角（"蔚来XX现已正式上市"）
2. 句式：短句+分点（🔸✅）
3. 标点：感叹号用于里程碑标题，正文克制
4. 词汇：日拱一卒/一起加电/创领新境/可充可换可升级
5. 情绪：温和自豪（"感谢大家的选择与认可"）
6. 结构：产品发布=创领新境开场→价格→卖点分点→预约CTA；里程碑=数字+换算+感谢收尾
7. 话题：产品/技术/基建/荣誉/公益/明星
8. 数字：必换算成用户价值（省83小时/少花2.6万/够一个家庭用一年）
9. 互动：📲欢迎预约试驾
10. 排版：🔸✅ 分点符号，#话题 标签
